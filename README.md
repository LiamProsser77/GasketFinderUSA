# GasketFinderUSA

GasketFinderUSA is a directory for finding gasket manufacturers and vendors across the United States.

## Features

- Search gasket companies
- Find manufacturers and suppliers
- View company websites
- Browse gasket products
- Find vendors by location

## Built With

- HTML
- CSS
- JavaScript
- GitHub Pages

## Goal

To create a simple and reliable resource for discovering gasket companies throughout the United States.
